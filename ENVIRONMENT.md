# Environment

The retained clean replay used Python 3.12.11, NumPy 2.3.5 and SciPy 1.17.0. The exact gap certificate uses only the Python standard library. A Python 3.14 environment without the pinned scientific dependencies was unsuitable and is not treated as a mathematical failure.

Install with `python -m pip install -r requirements.txt`, then follow `REPLAY.md`. LaTeX compilation is a separate rendering check.
